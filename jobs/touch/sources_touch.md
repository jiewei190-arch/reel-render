# Sources: touch ("How a touchscreen knows where your finger is")

| Claim in the reel | Source |
|---|---|
| Capacitive screens: an insulator (glass) coated with a transparent conductor, typically indium tin oxide (ITO) | Wikipedia, "Touchscreen" https://en.wikipedia.org/wiki/Touchscreen |
| The human body conducts electricity; a finger distorts the screen's electrostatic field, which the controller measures as a capacitance change | Wikipedia, "Touchscreen" |
| Mutual capacitance: a grid of crossing electrodes, each crossing acts as a capacitor; pulses are applied to conductors and a finger reduces the capacitance at nearby crossings; it allows multi-touch | Wikipedia, "Touchscreen" |
| Drive lines (rows) and sense lines (columns) cross at sensing points; the output is a 2D matrix with one value per node; every node is measured independently so several fingers can be tracked | US patent text on mutual-capacitance touch sensing (USPTO 8,766,930 and related: image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/8766930) |
| Projected capacitance can detect a finger near the glass, not only on it | Wikipedia, "Touchscreen" |
| Some capacitive screens cannot detect a finger through electrically insulating gloves | Wikipedia, "Touchscreen" |
| A capacitive stylus works with a conductive (rubber) tip that connects the user's finger to the tip | Wikipedia, "Touchscreen" |

## Dropped / unverified
- Real capacitance values (a patent example mentions about 1 pF dropping to about 0.7 pF): not used. The on-screen "50 -> about 30" readings are **made-up illustrative units**, labelled as such on screen.
- How often the phone scans the grid: no reliable source found. **Dropped.**
- "Plastic styluses do nothing": the source describes conductive-tip styluses; the plain-plastic case is an inference from the same principle, shown as "plastic tip: nothing".
- Hovering detection varies by device; the reel only says it "can" notice a hovering finger.
