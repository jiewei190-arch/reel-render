# PROPS_PACK_REPORT: the shared props pack for law3d, biz3d and cyber3d

Branch `engine/props-pack` (from `engine/law-hero`, which carries the law3d hero props on top of `engine/all`), draft
PR #106 into `engine/all` (not merged).

**Why.** Five Shorts failed the AI editor because the SUBJECT of the story could not be shown: the monkey-selfie lawsuit
showed a man silhouette, and the Zune rendered as a modern notch smartphone (also Lucy v. Zehmer, the Sherwood
"pregnant cow" case, Juicero). The kits only had what their own hero sets covered (law3d 15, biz3d 13, cyber3d 10).

## 1. What was built

**`src/props/pack.tsx`**: one shared module of **36 hero-prop kinds**, generic, ORIGINAL and low-poly (no logo, no
trade dress: the music player has a plain three-button row and a menu bar, never a click wheel or a squircle pad; the
console, headset, speaker, drone and vehicles are generic shapes; labels and screens go through the brand check).

| group | kinds (kind params) |
|---|---|
| animals (10) | `monkey` (`holding: "camera"`: a selfie), `cow` (`spots`, default true), `dog`, `cat`, `horse`, `pig`, `chicken` (`variant`: hen / rooster), `shark`, `bird`, `rabbit` |
| gadgets (12) | `mp3Player` (`screen`), `juicer`, `gameConsole` (+ controller), `vrHeadset`, `smartwatch` (`screen`), `drone`, `tablet` (`screen`), `flipPhone` (`screen`), `digitalCamera`, `laptop` (`screen`; law3d only: biz3d / cyber3d keep theirs), `smartSpeaker`, `headphones` |
| vehicles (4) | `sedan`, `pickup`, `airplane` (small high-wing prop plane), `boat` (motorboat on a water patch) |
| everyday (10) | `shoppingCart`, `cashRegister` (`screen`), `vendingMachine`, `pizzaBox`, `sodaBottle`, `shoe` (`variant`: sneaker / heel; law3d / cyber3d: biz3d keeps its sneaker), `wristwatch` (`screen` "HH:MM" sets the hands), `ring` (diamond, in its box), `briefcase`, `suitcase` |

- **Same params as the existing hero props**: `color`, `label`, `lines`, `at`, `scale` (= `s`), `spin` (+ `yaw`, `motion`,
  `hit`), plus the kind params above. Where the label goes: animals wear a round name tag on a red collar; vehicles carry
  it on the plates / hull / side; briefcase and suitcase on a paper luggage tag; the juicer on the juice pouch; the
  vending machine on its lit header; the pizza box on the lid and the box front.
- **Validation** (`packParamError`, called by all three compilers): `holding` only on the monkey (and only "camera"),
  `spots` only on the cow, `variant` per kind, `screen` only on screen kinds (≤ 18 characters, brand-checked; a
  wristwatch needs a valid "HH:MM"); a pack param on a non-pack prop is an error. The shared brand list
  (`src/library/hero.ts`) gained the new subjects' marks (ZUNE, IPOD, JUICERO, PLAYSTATION, XBOX, OCULUS, FITBIT, GOPRO,
  ALEXA, ROLEX, CESSNA, ...), so e.g. `"screen": "ZUNE HD"` is refused.
- **Idle loops** (deterministic, pure functions of t and seed, no motion blur): every animal blinks (~3.4 s) and
  breathes, plus a tail wag / sway / swish, ears, head bob or nose twitch; drone rotors turn while it hovers, the plane's
  propeller turns, the boat bobs on ripples, the juicer presses and drips, the soda fizzes, the watch's second hand
  ticks, the diamond glints, LEDs and speaker rings pulse.
- **Themed per kit** through a `PackTheme` each kit builds from its own palette and materials (`LAW_PACK_THEME`,
  `BIZ_PACK_THEME`, `CYBER_PACK_THEME` in each `hero.tsx`): law3d low-poly flat-shaded (`plastic(flat)`), wood / navy /
  gold, gold-on-navy screens; biz3d smooth satin `hmat`, green screen accent; cyber3d dark steel, screens / LEDs / thin
  edge strips in bloomed neon cyan (`neon()`).
- **Scale**: hero scale (0.6-1.5 m at scale 1, like the kit hero props). `PACK_LIFE` gives the life-size scale next to
  the cast (monkey 0.6, cow 1.3, sedan 3.2, ring 0.08 ...). Animals and vehicles are side-on, head / front to +x, the
  head turned toward the lens: shoot them from 3/4 front.

**Wiring** (existing props untouched; each kit's own kinds win a name clash): `LawHeroKind` / `BizHeroKind` /
`CyberHeroKind` = own kinds + `packKindsFor(own)`; `*_HERO_KINDS`, `*_HERO_BOX`, `*_HERO_DEFAULT` include them, so the
compilers' kit lists, camera targets, clip / framing QA, the frame-0 opener (F2 hero size) and the clip adapters see the
pack props with no further change. Dispatch: `LawHero`, `BizHero`, `CyberHero` hand a non-own kind to `PackHero` with
the kit theme; the recipe types gained `holding`, `spots`, `screen` (+ `variant` in biz / cyber).

## 2. The catalog (`src/props/catalog.json`)

Generated by `node tools/props_catalog.mjs` (`--check` exits 1 when it is stale) from the kit code itself, so it can
not drift from what the compilers accept. **86 kinds** (every hero kind of the three kits, own and pack, and the plain
kit pieces: gavel, newspaper, tower, route ...), each with `kits`, `hero`, `what` (per kit where the kits differ),
`params` (+ `paramsKits` when only some kits take them), for pack props `group`, `lifeScale`, `default`, and generous
`keywords` (731 distinct); plus `index`: lowercase keyword → kinds. Examples:

| story subject | index lookup |
|---|---|
| monkey selfie | "monkey", "macaque", "selfie", "monkey selfie" → `monkey` (`holding: "camera"`) |
| Lucy v. Zehmer (a farm sold on a restaurant check) | "contract", "napkin contract", "deal" → `contract` (law3d); "farm" → `cow`; "house" → `house` |
| Sherwood v. Walker ("Rose", a barren cow) | "cow", "pregnant cow", "barren cow", "cattle" → `cow` (`spots: false`, `color` any) |
| Juicero | "juicero", "juice press", "juice pack" → `juicer` |
| Zune | "zune", "mp3", "music player", "ipod" → `mp3Player` |

Counts per kit (hero / of which pack / plain): law3d 51 / 36 / 10, biz3d 47 / 34 / 6, cyber3d 45 / 35 / 6.

## 6. Notes / limits

- Animals and vehicles have one pose each (standing / sitting; no walk cycle): a pack prop moves with the kit's prop
  `motion` (bob, popIn, dropIn, turntable, path in cyber3d) like any hero prop.
- Name clashes keep the kit's own version: law3d `car` and `phone`, biz3d `laptop` and `shoe` (no `variant` there),
  cyber3d `laptop`. The catalog's `what` / `paramsKits` say which one a kit gets.
- The five failed Shorts are not in this repo, so they were not rebuilt here; their subjects now resolve in the catalog
  (section 2) and can be put at frame 0 with the kits' existing hero-prop opener pattern.
