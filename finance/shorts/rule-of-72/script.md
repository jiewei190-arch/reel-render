# rule-of-72

- **Spoken:** 64 words, voice 25.05 s (D2 Chatterbox, exaggeration 0.3, cfg 0.3).
- **Hook:** line 1, spoken from 0.0 s, no intro.
- **Ending:** stops mid-thought, no call to action; the last line runs straight into line 1 when the Short loops.
- **Loop:** S18 ("So remember...") returns to the S01 lens: Saver lifts the glowing 72 block again; the loop cut lands on "One number".
