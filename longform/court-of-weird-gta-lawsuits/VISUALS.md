# VISUALS: what the viewer must see in each case

Hard rules for this video: **no game footage, no screenshots, no logos, no box art, no character likenesses, no real
people's likenesses.** Everything is a generic prop or set in the channel's stylised 3D look. Where a game is involved,
show a blank grey game case, a plain disc, a controller, or a CRT with abstract coloured blocks. Brand and game names
appear only as plain text on case cards. On-screen numbers match the narration.

## Rules for the whole video
- Countdown number card (10 ... 1) with the case name, year and court for at most two seconds, then the object.
- Three "?" cards (cases 8, 7, 4) mark the outcomes we could not confirm; they use the same design so honesty reads as a feature.
- Cases 7 and 1 get slower cuts, no comedy sound effects, and no stamps slammed with a bang.
- The streaming stick, the TV and the phone are unbranded shapes.
