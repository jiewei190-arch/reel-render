# VISUAL NOTES: From $2 Billion To Nothing: How THQ Lost Everything

For the `doc` kit, theme `biz` (3D shots from `biz3d`). One row per beat: the words that start it, what the viewer sees,
and the scene type. Every number on screen is a number the narration says at that moment.

**Rules for this video**
- No logos, no console or game artwork, no character likenesses, no box art, no game footage. Company and game names
  appear as plain text only. Consoles are grey generic boxes labelled "CONSOLE"; game boxes use the `box` hero prop with
  generic labels ("WRESTLING", "CARTOON", "SHOOTER", "RACING").
- The tablet is the hero object. The kit has no tablet prop today: either add a generic one (white slate, stylus on a
  cord, label "DRAW") or use `block` (white, flat) with the `label` action "DRAW". Never copy the real product's shape
  details or colours beyond "white slate with a pen".
- People are the kit's generic executives. Name cards as plain text ("Brian Farrell, CEO"). No likenesses.
- Quotes on `quote` scenes must be re-read at the URL in `sources.md` before the render.
