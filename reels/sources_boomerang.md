# Sources: boomerang (why a returning boomerang comes back)

Both pages fetched with WebFetch on 2026-10-27; every claim below was read on the page.

| Script line | Source |
|---|---|
| A returning boomerang has an aerofoil shape similar to an aeroplane wing (curved top, flat bottom) | https://archive.imascientist.org.uk/physics20-zone/question/why-do-boomerangs-come-back/index.html (Fielder; Barron) |
| Each end forms an airfoil | https://hyperphysics.gsu.edu/hbase/brng.html |
| The throw gives it spin ("angular velocity perpendicular to its path") | https://hyperphysics.gsu.edu/hbase/brng.html |
| The top edge travels faster with respect to the air and gets more lift | https://hyperphysics.gsu.edu/hbase/brng.html ; imascientist (Barron, Monk) |
| The uneven lift tilts the boomerang so it flies in a curve | imascientist (Barron: "This torque tilts the boomerang so that it flies in a curve"; Monk) |
| The changing direction of the lift makes it follow a circle, back toward the thrower, when thrown at the right angle | imascientist (Fielder); HyperPhysics ("circling back toward the thrower") |
| For a right-handed thrower the faster side is typically the right-hand side; it is pushed to the left | imascientist (Monk) |
| Most boomerangs were built for hunting and don't return | imascientist (Fielder) |
| Quite often the curve isn't enough to make it return | imascientist (Monk) |
| A spinning frisbee shows a similar effect | imascientist (Monk) |

Definition line ("lift is the push that keeps a wing up") is a plain-language gloss, not a sourced claim.
Dropped: why the top arm moves faster (sources state the effect, not the cause); the word "torque" and "precession"; any numbers.
