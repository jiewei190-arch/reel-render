# inkwash (our code, technique from Lemo ink-wash STYLE.md)
Rice paper, 5 ink tones, wet layer (blurred, multiply) + dry layer (bristle strokes, flying white), blank paper as space, one vermilion seal. API in inkwash.js: createInk, stroke, wash, mist, mountain, waves, drop, inscribe, seal, subtitle. ~0.1 s/frame at 1080x1920.
