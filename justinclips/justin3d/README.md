# Justin 3D: rigged host character for Justin clips

Justin is the host of the Justin clips Shorts channel (weird true history), built as a rigged 3D character in a stylised animated-film look. He follows the owner's pick, **concept D** (`concept/justin_D.png`), with the two approved changes:

1. **One bright accent.** The bomber has a bright orange lining that shows at the collar, the cuffs and the open front edges. The chest "J" is metallic gold with a slight sheen and a clear coat.
2. **A wide expression range.** The face has 24 controls: smile, smirk L/R, shock, cringe/grimace, frown, brow raise/furrow/sad per side, blinks, squint, wide eyes, eye look, and lip-sync mouth shapes.

He is fully original. Every mesh is generated by `build_justin.py` from signed-distance-field shapes (marching cubes). He is not based on any real person, existing character, base mesh or scan.

## Render Justin for a Short

You need Blender 4.0+ on PATH (`apt install blender`), plus `python3-numpy` and `python3-skimage` for the rebuild only, `ffmpeg`, `xvfb` (EEVEE needs a virtual display when headless) and Pillow.

```bash
# animated clip from a sequence + voice, composited on green (chroma key in the edit)
python3 render_justin.py --seq my_seq.json --audio vo.wav --audio-offset 0.3 --bg green --out justin_green.mp4

# with real alpha for compositing over the Toon 3D scenes (ProRes 4444 .mov)
python3 render_justin.py --seq my_seq.json --bg transparent --out justin_alpha.mov

# keep the RGBA PNG frames too
python3 render_justin.py --seq my_seq.json --bg transparent --out j.mov --keep frames_dir/

# one transparent still
python3 render_justin.py --pose point --expr skeptical --framing medium --bg transparent --still point.png
```

Useful flags:
- `--framing full|medium|close|bust` (`bust` is chest-up, for reaction cut-ins in a corner of a Short)
- `--cam-yaw DEG` turns the camera around him.
- `--scale 0.75 --samples 16` renders faster, then upscales to `--res` (default 1080x1920).
- `--jobs N` runs N Blender processes in parallel.

On this 4-CPU cloud box a full-res frame takes about 50 s, so `test.mp4` was rendered with `--scale 0.75 --samples 16 --jobs 3`.

### Reaction cut-ins over a finished Short

```bash
cd preview_whale && ./make_preview.sh /path/to/base_video.mp4   # writes ../preview_exploding_whale.mp4
```

Copy `preview_whale/` for a new Short. Edit the four sequence JSONs (expressions and timing) and `plan.json` (where each clip sits, when it starts and which edge it slides in from). Keep Justin in the lower third, clear of the captions.

### Sequence format

```json
{ "duration": 8.0, "fps": 30, "framing": "medium",
  "audio": "line.wav", "audio_offset": 2.15, "pop_in": 0.0, "pop_out": 7.8,
  "keys": [
    {"t": 0.0, "pose": "look_away", "expr": "neutral", "face": {"look_x": 0.7}},
    {"t": 1.3, "pose": "double_take", "expr": "shock", "dur": 0.14, "ease": "snap"},
    {"t": 4.4, "pose": "cross_arms", "expr": "smirk", "dur": 0.5}
  ] }
```

- Leaving out `pose` or `expr` keeps the current one.
- `face` adds raw face controls on top.
- `pop_in` / `pop_out` are the times (s) of a quick scale pop on and off. Leave them out for no pop.
- `ease` is one of `smooth`, `snap` (overshoot), `linear` or `hold`.

These layers are added automatically:
- breathing and idle sway;
- random blinks every 2.3 to 4.4 s;
- lip sync from the audio loudness:
  - jaw open follows the RMS;
  - "ee" (wide) and "oo" (round) shapes come from the spectral centroid;
  - the lips press shut at word ends;
- a small head bob while talking.

**Poses:** `idle`, `idle_b`, `wave`, `wave_b` (alternate the two for a waving loop), `point` (at the viewer), `point_side` (at on-screen text), `shrug`, `facepalm`, `cross_arms`, `look_away`, `double_take`, `explain`, `explain_both`, `thumbs_up`.

**Expressions:** `neutral`, `smile`, `grin`, `smirk`, `shock`, `cringe`, `angry`, `sad`, `skeptical`, `laugh`, `thinking`, `blink`.

Add new poses and expressions to `justin_lib.py`. Arms are written as world directions or IK targets, so new poses need no bone-axis knowledge.

## Rig

- **Body.** `root` (pop-in scale and hop) → `hips` → `spine` → `chest` → `neck` → `head`. Each side has `shoulder`, `upper_arm`, `forearm` and `hand`, five 3-bone fingers including the thumb, and `thigh`, `shin` and `foot`. Skin weights are computed procedurally. Jacket weights are taken on the jacket's mid-surface, so both shell faces move together. The palm twist sits at the wrist (inside the round cuff) so the sleeves never candy-wrap.
- **Face.** There are custom properties on `Justin_rig`: `smile`, `smirk_L/R`, `frown`, `open`, `wide`, `round`, `press`, `grimace`, `shock`, `brow_up_L/R`, `brow_furrow_L/R`, `brow_sad_L/R`, `blink_L/R`, `squint`, `eyes_wide`, `look_x/y` and `cheek_L/R`. Drivers send them to:
  - mouth shape keys (the mouth is a projected decal mesh with teeth and tongue bands);
  - head shape keys (jaw drop, cheek raise);
  - brow shape keys;
  - the eyelid bones (lids are spherical shells with a lash line);
  - the eye bones.

  You can animate all of them in Blender's UI too.

## Look

- Stylised proportions: bigger head (x1.10) and chunky hands (x1.15).
- Large glossy eyes with a clear coat, so they catch the light.
- Subsurface skin with baked rosy nose, cheeks and ears, and a faded haircut on the sides.
- Clean SDF hair shapes.
- EEVEE soft studio lighting: key, fill, two rims and a face light, AgX "Punchy" view transform.
